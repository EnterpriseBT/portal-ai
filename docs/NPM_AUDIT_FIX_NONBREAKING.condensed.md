# Non-breaking npm audit fixes — Condensed design (#551)

**Issue:** [EnterpriseBT/portal-ai#551](https://github.com/EnterpriseBT/portal-ai/issues/551) · Task · **small / condensed** (discovery + spec + plan + smoke in one doc).

**Why.** `npm audit` (full advisory DB) reports 59 findings against the root `package-lock.json`; the majority are transitive deps with **non-breaking patch fixes**. A plain `npm audit fix` (no `--force`) changes ~130 packages and clears them — 5 critical + ~20 high — with no major upgrades. This ticket applies that fix + a `drizzle-orm` patch bump the fixer skips, validated by the full suites. Touches the lockfile monorepo-wide plus four `package.json` files; no source changes expected.

## Decision — apply non-breaking fixes only, in one lockfile commit

`npm audit fix` **without `--force`** (never `--force` — that would downgrade drizzle-kit/storybook/exceljs and major-bump astro/maplibre/uuid/csv-parse, all owned by their own tickets #547–#550, #552–#553). Then bump the `drizzle-orm` `^0.45.1` ranges → `^0.45.2` and the devops-cli exact pin → `^0.45.2` (clears the remaining **high**, which the fixer leaves because of the exact pin). Verify no runtime dep's patch forces a code change; if one does, note it and promote sizing. Lockfile churn is broad but the change is mechanical and semver-patch.

## Plan — 1 slice

**Files**
- `package-lock.json` — regenerated by `npm audit fix` (~130 packages).
- `package.json`, `apps/api/package.json`, `packages/admin-cli/package.json` — `drizzle-orm` `^0.45.1` → `^0.45.2`.
- `packages/devops-cli/package.json` — `"drizzle-orm": "0.45.1"` → `"^0.45.2"` (or exact `0.45.2` to match the pin convention there).

**Tests** — no new tests; this is a dependency bump validated by the existing suites. Run, in order: `npm run build`, `npm run type-check`, `npm run lint`, `npm run test` (unit). Integration (`@testcontainers`) runs in CI; run locally only if Docker is available. Green across all four is the gate. A red result that traces to a patched runtime dep (`axios`/`undici`/`ws`/`postcss`/`lodash`/`vite`) is a real finding → fix or promote.

## Smoke (manual, against your dev stack)

1. `npm run build && npm run type-check && npm run lint && npm run test` locally → all green.
2. `npm audit` → the 5 critical + ~20 high non-breaking advisories are **gone**; only the known major-upgrade / downgrade-only remainder stays (astro, maplibre, uuid, csv-parse, testcontainers; drizzle-kit/storybook/exceljs).
3. Start the dev stack (`npm run dev`), load the web app, sign in — confirm no runtime break from the patched deps (auth, a page render).
4. Exercise one connector sync or portal render — deps touched include `axios`/`undici`/`ws`; confirm the network + worker paths still work.
5. `apps/site` build still bakes prices (its `vite`/`postcss` chain moved).

- Adding `npm audit` as a **gate** — #545 is deliberately informational; this ticket doesn't change that.
